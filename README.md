# GPU_VG_MC

This project provides a GPU-accelerated Monte Carlo simulation for the Variance Gamma (VG) model, along with a PyTorch-based neural network for learning and analyzing option prices generated by the simulation.

## Structure

- `VG_cuda_MC.cu` and `VG_cuda_algorithms.cu`: CUDA C++ code for generating training and testing datasets using the VG model.
- `train.py`: Python script for training, validating, and evaluating a neural network on the generated data.

## Requirements

- CUDA-capable GPU and CUDA toolkit (for running `.cu` files)
- Python 3.7+
- See `requirements.txt` for Python dependencies

## Usage

### 1. Generate Data

Compile and run the CUDA code to generate CSV datasets:

```sh
nvcc -O3 VG_cuda_MC.cu -o vg_mc -lcurand
./vg_mc
```

This will create `Training/` and `Testing/` folders with CSV files.

### 2. Train the Neural Network

Install Python dependencies:

```sh
pip install -r requirements.txt
```

Train and evaluate the model:

```sh
python train.py --train_folder Training/ --test_folder Testing/ --epochs 10 --batch_size 256 --device cuda:0
```

You can adjust arguments as needed (see `python train.py --help`).

### 3. Results

- Model checkpoints are saved in the `checkpoints/` directory.
- Training and validation loss curves are saved as `VG_loss_curve.png`.
- The script also provides evaluation metrics and plots for monotonicity and convexity analysis.

## Notes

- Ensure your GPU drivers and CUDA toolkit are properly installed.
- The neural network expects the CSV files generated by the CUDA code.
